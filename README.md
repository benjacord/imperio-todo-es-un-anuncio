<p align="center"><b>TODO ES UN ANUNCIO</b><br>
Una skill de <b>Imperio Agéntico</b> para el curso <i>Anuncios con IA</i> de Benja (@bencord).</p>

---

Le pasas a Claude una carpeta con TODO lo que tengas, sin ordenar: clips, videos, fotos, capturas, audios, mensajes de clientes, notas. Claude revisa cada pedazo, le encuentra un propósito y te arma anuncios con la estructura de siempre:

**Gancho** (3 segundos) → **Cuerpo** (una idea) → **CTA** (una acción)

Van a tu **laboratorio mixto**: un conjunto aparte dentro de tu campaña de laboratorio.

## Cómo se instala

- **En la app de Claude:** Configuración → Capacidades → Skills → sube el archivo `todo-es-un-anuncio.zip` de este repositorio.
- **En Claude Code:** copia la carpeta `todo-es-un-anuncio` dentro de `~/.claude/skills/`.

## Cómo se usa

Solo háblale:

> "Toma, aquí tienes una carpeta con todo. Recientemente empecé a trabajar con esta persona y quiero anuncios con esto."

Claude te hace como mucho 3 preguntas (qué vendes, a dónde manda el anuncio y a quién le hablas), te propone entre 5 y 15 anuncios en una tabla y, si puede, los arma.

**Nada inventado:** si no es un cliente real, una cifra real o un mensaje real, no va.
